# Brief — m02-spec-illustration

asset_id: m02-spec-illustration
course_id: m02
purpose: explicar una especificación bien definida junto al texto de la lección
learning_objective: distinguir una petición ambigua de una especificación con decisión, alcance, supuestos, evidencia y condición de terminado
pedagogical_question: ¿Qué transforma una petición vaga en una tarea que un agente puede ejecutar y una persona puede verificar?
why_not_text_or_svg: **SVG es mejor.** La relación entre los cinco elementos debe ser estable, legible y accesible; una imagen generada podría inventar texto, omitir una relación o sugerir precisión inexistente. Por eso no se genera raster para este activo.
subject: cinco piezas de papel abstractas que pasan de una nube irregular a una ruta delimitada con punto de verificación
style: SVG codificado con formas planas de Atlas de criterio; no es un diagrama técnico ni contiene texto incrustado
palette: marfil cálido, azul tinta, ocre apagado y verde azulado
composition: horizontal 16:9; bloque ambiguo a la izquierda, piezas delimitadas y ruta verificable a la derecha
aspect_ratio: 16:9
exact_text: none
constraints: sin texto, letras, números, logos, personas, datos empresariales, marcas de agua o afirmaciones de proceso exacto
avoid: etiquetas dentro del SVG, flechas que prometan una receta lineal, UI, bloques de código o iconos de proveedor
alt_text_draft: Formas de papel irregulares se organizan en cinco piezas conectadas y una ruta que termina en una marca de verificación.
generation_tool: SVG manual en código; no se usó generador de imágenes
review_status: pending

## Decisión

No se genera una variante raster. El master y la versión web son el mismo SVG accesible; el texto adyacente debe nombrar los cinco elementos antes de usar el visual.
